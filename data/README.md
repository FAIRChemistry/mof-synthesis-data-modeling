# Data

This folder contains two example datasets.

## [Synthesis of Fe–terephthalate based on CSV](./Fe-terephthalate)

This folder contains the dataset for the synthesis of Fe–terephthalate.
The synthetic procedures and product masses were recorded in the CSV format, which has been converted to MOFSY format.

## [Synthesis of MOCOF-1 based on Sciformation electronic lab notebook](./MOCOF-1)

This folder contains the dataset for [the synthesis of MOCOF-1](https://www.nature.com/articles/s44160-024-00719-x), consisting of 183 entries.
See [the specific Readme](./MOCOF-1/README.md) for details.

## [Synthesis of MOCOF-1-(OH)2 based on Chemotion electronic lab notebook](./MOCOF-1_Chemotion)

This folder contains the dataset for the synthesis of MOCOF-1-(OH)2 (unpublished).
See [the specific Readme](./MOCOF-1_Chemotion/README.md) for details.
